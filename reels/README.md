# reels/ — рабочие папки для монтажа (скилл `reels-montage`)

Что куда класть:

- **input/** — сырое видео для монтажа (один или несколько файлов).
- **inserts/** — вставки (скрины/фото/видео) ТОЛЬКО для текущего ролика.
- **context_assets/** — постоянные вставки на все ролики (скрины, стикеры, демо-видео). Не удалять.
- **library/** — файлы шаблона: полоски (strip), градиент (gradient), мемы. Не удалять.
- **stickers/** — иконка-стикер у субтитров (PNG без фона).
- **music/** — фоновая музыка (mp3).
- **sfx/** — звуки появления вставок (mp3/wav).
- **fonts/** — шрифты: заголовочный (condensed), субтитровый (sans), рукописный.

Папки `done/` и `output/` заполняет Claude сам во время монтажа: `done/` — использованные исходники и одноразовые вставки, `output/` — готовый ролик `<тема>-final.mp4`.

Сырые исходники, разовые вставки и готовые рендеры (`input/`, `inserts/`, `done/`, `output/`) в git не коммитятся (см. `.gitignore`) — это рабочие файлы конкретного ролика. Шаблонные файлы (`library/`, `context_assets/`, `stickers/`, `music/`, `sfx/`, `fonts/`) коммитятся, чтобы сохраняться между сессиями.
