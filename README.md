# 🎬🎨 Дизайн и монтаж со вкусом

Практическая библиотека скиллов для Claude Code: дизайн интерфейсов, SVG и моушен, Reels-монтаж и типографика.

Синхронизировано из [elianoraMullagalieva/design-montazh-so-vkusom](https://github.com/elianoraMullagalieva/design-montazh-so-vkusom).

## Что внутри

- `skills/montage-svg-typography` — **полная рабочая папка монтажа**: SVG, визуальные подложки, Reels-скиллы, типографика, рендер-инструменты, HTML-эталоны, исходные видео и шрифты.
- `skills/design-ui` — арт-дирекция, UI/UX, дизайн-системы, типографика, интерфейсные стили и редизайн.

Монтажная папка синхронизирована с исходником целиком: без оптимизации, удаления эталонов и замены видео. Видео хранятся через Git LFS в исходном репозитории — здесь присутствуют только LFS-указатели, реальные файлы нужно подтягивать из оригинала.

## Как установить скилл

1. Для полного пакета с эталонными видео установи Git LFS и скачай видео из исходного репозитория:

   ```bash
   git lfs install
   git clone https://github.com/elianoraMullagalieva/design-montazh-so-vkusom.git
   cd design-montazh-so-vkusom
   git lfs pull
   ```

2. Открой Claude Code.
3. Перетащи нужную папку скилла в чат или укажи путь к ней.
4. Напиши: «Установи этот скилл и используй его в работе».

Для коммерческого проекта перед использованием любого внешнего ассета или шрифта всегда отдельно проверь лицензию и права распространения. Manrope и JetBrains Mono сопровождаются лицензиями OFL-1.1; условия для остальных файлов нужно подтверждать отдельно.
