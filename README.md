# Telegram-бот

Простой шаблон Telegram-бота на Python (aiogram 3). Умеет отвечать на `/start`,
`/help` и повторяет (эхо) любое текстовое сообщение.

## Запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Получите токен бота у [@BotFather](https://t.me/BotFather).

3. Скопируйте `.env.example` в `.env` и вставьте токен:

   ```bash
   cp .env.example .env
   ```

4. Запустите бота:

   ```bash
   python main.py
   ```

## Структура проекта

```
main.py            # точка входа, запуск polling
bot/config.py       # загрузка настроек из .env
bot/handlers.py      # обработчики команд и сообщений
```

## Дальнейшее развитие

Добавляйте новые обработчики в `bot/handlers.py` (можно разбить на несколько
роутеров/файлов при росте функционала), а также FSM-сценарии, инлайн-кнопки,
подключение базы данных и т.д.
