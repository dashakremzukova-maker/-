# Натальная карта стиля

Шаблон персонального стайлбука: один HTML-шаблон (`template.html`) + данные клиентки в `client.json` → PDF из страниц-сторис 1080×1920.

Примеры: [`examples/Натальная_карта_стиля_Вера_FULL.pdf`](examples/Натальная_карта_стиля_Вера_FULL.pdf) и [`…_SHORT.pdf`](examples/Натальная_карта_стиля_Вера_SHORT.pdf) — выдуманная клиентка, фото в демо заменены иллюстрациями.

## Один раз: установка

Нужен [Node.js](https://nodejs.org) 18+.

```bash
npm install
npx playwright install chromium
```

## Новый клиент за 3 команды

**1. Импорт анкеты.** В таблице «Анкета клиента — ответы»: Файл → Скачать → CSV. Номер строки — как в таблице (строка 1 — заголовки).

```bash
node import.js answers.csv --row 5
```

Появится `clients/Имя_Фамилия/client.json` (раздел `anketa` заполнен, `stylist` — пустая заготовка) и папка `photos/`. Если в анкете есть обхваты, скрипт напишет подсказку по типу фигуры, а часы по сферам (в.9) сразу разложит в `lifestyle.spheres`.

**2. Заполнить `stylist`.** Кидаем фото клиентки в `clients/Имя_Фамилия/photos/` и открываем `client.json` в любом редакторе. В полях фото указываем просто имя файла: `"cover_photo": "face.jpg"`. Образец заполнения — `clients/Вера_Соколова/client.json`.

**3. Экспорт.**

```bash
node export.js clients/Имя_Фамилия/client.json
```

Результат — `clients/Имя_Фамилия/Натальная_карта_стиля_Имя.pdf`. Добавьте `--html`, чтобы получить ещё и HTML-версию для телефона.

## Полезно знать

- **FULL / SHORT.** Режим задаётся полем `"mode"` в начале `client.json`. SHORT — страницы 0, 1, 2, 4, 5, 9, 11, 14, 15. Для одного экспорта режим можно переключить флагом `--mode short`.
- **Пустое не выводится.** Незаполненный блок исчезает, а если пуста вся страница, она пропускается. В консоли видно, какие страницы пропущены.
- **Цитаты клиентки.** Если `request.goal`, `request.success` и `request.plans` пустые, берутся ответы на вопросы 3, 5 и 6 как есть. Вопросы 2, 4, 36 и 37 в PDF не выводятся.
- **Тип фигуры.** Подсказка по обхватам сохраняется в `figure.silhouette_hint`. Решение принимает стилист в поле `figure.silhouette` (например, `"X — песочные часы"`); пока оно пустое, в PDF попадает подсказка. В `figure.measurements` можно дописать обхват плеч.
- **Шпаргалка (стр. 14).** Если `cheatsheet` не заполнена, она собирается сама из выводов: правила, первые 6 свотчей, первые 3 образа.
- **Много текста.** Если блок не влезает в страницу, шаблон слегка уменьшает его, а экспорт пишет предупреждение («стр. 4: текст уменьшен до 94 %»). В таком случае лучше сократить текст.
- **Фото.** Сжимаются автоматически. Если PDF выходит больше 15 МБ, экспорт повторяется с более сильным сжатием. Формат HEIC (iPhone) браузер не читает, такие фото сохраните как JPG.
- **Шрифты** (Playfair Display, Manrope) грузятся из Google Fonts, поэтому экспорту нужен интернет.
- **Постоянные данные стилиста** (имя, контакты) лежат в `stylist-profile.json` и подставляются в каждый новый `client.json` при импорте.
- Папки реальных клиентов в git не попадают (см. `.gitignore`).

## Страницы

| № | Страница | Поля `stylist` |
|---|---|---|
| 0 | Обложка | `meta` |
| 1 | Запрос | `request` (или в.3, 5, 6) |
| 2 | Образ жизни, диаграмма | `lifestyle` |
| 3 | Ядро (типаж) | `typage` (`yin_yang`: 0 — инь, 100 — ян) |
| 4 | Цвет + сочетания | `color` (шкалы 0–100) |
| 5 | Фигура + приёмы | `figure` |
| 6 | Внутренний код | `inner_code` |
| 7 | Стиль | `style` |
| 8 | Формула гардероба | `wardrobe` |
| 9 | Формулы образов | `looks` (до 8, по 4 на страницу) |
| 10 | Детали | `details` |
| 11 | «Не твоё» | `not_yours` |
| 12 | Волосы и макияж | `hair_makeup` |
| 13 | Шопинг | `shopping` |
| 14 | Шпаргалка | `cheatsheet` (или авто) |
| 15 | Финал | `final` |

Цвета и шрифты бренда задаются в начале `<style>` в `template.html` (переменные `--red`, `--black`, `--brown`, `--paper`…).
