# Натальная карта стиля — сборщик

Собирает персональный стайлбук (PDF 1080×1920, как сторис) из папки клиентки на Google Диске.
Дизайн и вёрстка взяты 1 в 1 из `образец/build_образец.py`.

## Установка (один раз)

```
pip install pillow pillow-heif python-docx playwright pymupdf
playwright install chromium
```

В `config.json` укажи путь к папке «натальная карта стиля» (синхронизированной через Google Drive для компьютера),
подпись стилиста и Telegram. Шрифты Playfair Display и Manrope лежат в `fonts/`.

## Как работать

1. В `клиенты/` создай папку «Имя Фамилия», скопируй шаблон справки, заполни, разложи фото по папкам,
   скачай справку в .docx (Файл → Скачать → Microsoft Word).
2. Напиши Claude: «Собери карту для Имя Фамилия».
3. Claude запускает

   ```
   python3 natal_card.py parse "клиенты/Имя Фамилия"
   ```

   Получаются `client.json` (данные справки + черновик текстов карты) и `проверка.md`
   (что распознано, что пустое, маленькие и повторяющиеся фото).
   Claude переводит текст на простой язык, сокращает, подбирает цвета и присылает всё одним сообщением.
4. После твоих правок Claude записывает тексты в `client.json` (`"status": "утверждено"`) и собирает:

   ```
   python3 natal_card.py build "клиенты/Имя Фамилия"
   ```

   PDF появится в `готово/Натальная карта стиля — Имя Фамилия.pdf`. Сборщик сам проверяет число страниц,
   размер (до 15 МБ) и ссылки (карточки направлений ↔ галереи, Telegram).

## Правила

- Имена папок читаются нестрого: регистр, лишние пробелы, ё/е, «образы типажи» = «образы типаж», «вверх» = «верх».
- Фото — jpg, jpeg, png, webp, heic, порядок по имени файла.
- Всё пустое в карту не попадает: нет текста и фото — нет страницы или блока.
- Если нужно поменять текст в карте — правь раздел `card` в `client.json` и запусти `build` ещё раз.
  `parse` не перезаписывает готовые тексты (только с флагом `--force`).
